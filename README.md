This repository contains Python implementations for solving two classic optimization problems: the Knapsack Problem and the Traveling Salesman Problem (TSP). Both problems are tackled using an evolutionary 
algorithm based on artificial intelligence (AI) techniques, including selection, crossover, mutation, and the selection of the best solutions to efficiently solve these NP-hard problems.

1.Knapsack Problem: Solved using an evolutionary algorithm to select the optimal combination of items that maximizes the total value while respecting the weight constraint of the knapsack.

2.Traveling Salesman Problem (TSP): The evolutionary algorithm searches for the shortest path that connects a series of cities, visiting each city exactly once and returning to the starting city.

The implementation includes:

Selection and crossover algorithms for generating new solutions.
Mutation mechanisms to explore different possibilities.
Evaluation and selection of the best solutions based on fitness functions.

This repository provides a solid foundation for experimenting with evolutionary algorithms and can be extended to solve other optimization problems.
